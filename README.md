# 🚀 QueueFlow

**QueueFlow** is a modern, premium PWA designed to help customers skip physical lines and help businesses manage their flow efficiently.

## ✨ Features
- **PWA Ready**: Install on Android/iOS for live notifications.
- **Real-time Updates**: Track your position in the queue instantly.
- **Business Dashboard**: Analytics and queue management for vendors.
- **Glassmorphism UI**: Built with Next.js 15 and Tailwind CSS.

## 🛠️ Tech Stack
- **Framework**: Next.js (App Router)
- **Styling**: Tailwind CSS
- **Icons**: Lucide-React
- **PWA**: next-pwa / manifest.json
